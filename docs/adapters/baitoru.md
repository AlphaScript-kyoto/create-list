## ページ構造メモ

| 種別 | URL パターン |
|------|----------------|
| 一覧 | `https://www.baitoru.com/.../jlist/...`（検索結果） |
| 詳細 | `https://www.baitoru.com/jobdetail/{数字}` |

### 一覧ページ

- 求人リンク: `a[href*='/jobdetail/']`
- 次ページ: 一覧 URL の末尾に `/page2` `/page3` …（「次へ」ボタンも補助）
- **株式会社バイトレ** は一覧の社名から判定し、詳細 URL に入れない（詳細を開かない）
- 大手キーワード（`config.json` の `exclude_name_keywords`）も一覧の社名で分かるものは除外

### 詳細ページ（事業主情報）

| CSV 列 | 取得元 |
|--------|--------|
| 企業名 | `#section-business-info` 先頭の企業名 |
| 郵便番号 | 所在地の先頭に 7 桁があれば分割。無ければ空欄 |
| 住所 | 事業主情報の「所在地」（郵便番号を除く） |
| 電話番号 | 「電話番号を表示する」→ ダイアログの「専用電話番号」（取れなければ CSV に出さない） |
| メールアドレス | 事業主情報にあれば。無ければ空欄 |
| 担当者名 | 事業主情報にあれば。無ければ空欄 |
| 掲載サイト | バイトル |
| 詳細URL | 求人ページ URL |
| 取得日時 | 収集時刻 |

## 使い方

1. 収集サイト: **バイトル** を選択
2. [開く] → 黄色い帯の Chrome で地域・キーワードを検索
3. 一覧（URL に `jlist`、求人カードが並ぶ画面）で [収集開始]
4. 社名と所在地が同じ会社は 1 件にまとまります

## 注意

- 電話番号はボタン操作後に表示されるため、1 件あたりの操作が増えます
- 電話番号が取れない求人は CSV に入れません
- 株式会社バイトレは一覧段階で除外します（詳細を開いて住所不一致になる無駄を避けるため）
- 大手企業は社名キーワード・従業員数上限でスキップします（`config.json` の `company_filter`）
- Governor の休憩設定を守り、短時間での大量アクセスを避けてください
