## ページ構造メモ

| 種別 | URL パターン |
|------|----------------|
| 一覧 | `https://www.ekiten.jp/g{ジャンル}/a{地域}/`（次ページは `/p2/`） |
| 詳細 | `https://www.ekiten.jp/shop_{店舗ID}/` |

### 一覧ページ

- 店舗リンク: `a[href*="/shop_"]`
- 次ページ: 同じ URL に `/p2/` `/p3/` を付けて進む

### 詳細ページ

| CSV 列 | 取得元 |
|--------|--------|
| 企業名 | `h1`、または概要の「店舗名」 |
| 郵便番号 | アクセス欄の `〒123-4567` |
| 住所 | 概要の「住所」。●付きの概要文からも拾う |
| 電話番号 | 概要の「電話番号」や ● 行を優先。無ければ「電話する」（`tel:` またはボタン表示後） |
| メールアドレス | 概要文にあれば |
| 担当者名 | ページに無いことが多いため空欄 |
| 掲載サイト | エキテン |

**電話番号が取れない店舗、090・080・070 の携帯電話は CSV に保存しません。**

## 使い方

1. 収集サイト: **エキテン** を選択
2. [開く] → 黄色い帯の Chrome でエリア・ジャンルを検索
3. お店のカードが並んだ一覧で [収集開始]
4. 詳細ページを開いた状態では収集できません
