## ページ構造メモ

| 種別 | URL パターン |
|------|----------------|
| 一覧 | `https://tabelog.com/.../rstLst/`（エリア・キーワードの検索結果） |
| 詳細 | `https://tabelog.com/{エリア}/Axxxx/Axxxxxx/{店舗ID}/` |

### 一覧ページ

- 店舗リンク: `a.list-rst__rst-name-target`（1 ページあたり約 20 件）
- オープン日: `.list-rst__newopen`（ニューオープン一覧）
- 次ページ: `a[rel="next"]` または「次の20件」

### 詳細ページ

| CSV 列 | 取得元 |
|--------|--------|
| 企業名 | JSON-LD の `name`（なければ `.display-name`） |
| 郵便番号 | JSON-LD の `postalCode` を `123-4567` 形式に整形 |
| 住所 | 郵便番号を除いた住所 |
| 電話番号 | JSON-LD の `telephone`、または店舗情報テーブルの「お問い合わせ」 |
| メールアドレス | ページに無いことが多いため空欄 |
| 担当者名 | ページに無いことが多いため空欄 |
| 掲載サイト | 食べログ |
| オープン日 | 詳細の `.rstinfo-opened-date`（なければ一覧の表示） |
| 詳細URL | 店舗ページ URL |
| 取得日時 | 収集時刻 |

**電話番号が取れない店舗は CSV に保存しません**（ニューオープンで未掲載のことがあります）。

## 使い方

1. 収集サイト: **食べログ** を選択
2. [開く] → 黄色い帯の Chrome でエリア・キーワードを検索（ニューオープンでも可）
3. 一覧（URL に `rstLst`、お店のカードが並ぶ画面）で [収集開始]
4. 店名と住所が同じ店舗は 1 件にまとまります
5. 郵便番号と住所は別の列になります（例: `601-8017` / `京都府京都市南区…`）

募集地フィルタをオンにすると、**住所に選んだ県・市が含まれる店舗だけ** を保存します。

## 注意

- 電話番号がない店舗はスキップします
- 大手チェーンを外したい場合は `config.json` の `exclude_name_keywords` に店名を追加できます
- Governor の休憩設定を守り、短時間での大量アクセスを避けてください
