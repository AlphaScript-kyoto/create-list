## 許可チェック

- [x] bot 判定があるため、過度なアクセスと 1 日の取得量に制限がある（ユーザー確認済み）

ステルス・プロキシ・判定回避は実装しません。既存の Governor（件数ごとの休憩・ページ間待機）と、120 件キャップだけでペースを守ります。

## 画面の仕組み

検索すると、だいたい次のように見えます。

```text
左（一覧）                 右（詳細パネル）
┌──────────────┐          ┌──────────────┐
│ 店A  ★4.2    │ クリック │ 店A の詳細     │
│ 店B  ★3.8    │ ─────→ │ 住所・電話・HP │
│ 店C  ...     │          │ 営業時間 など  │
└──────────────┘          └──────────────┘
```

- 一覧カードは要約（店名・星・カテゴリ程度）。電話や住所はカードを開いたあとに出ることが多い
- 「個別ページ」は別タブのホームページではなく、**同じマップ画面の中の詳細パネル**（SPA）
- 一覧のままでは CSV の列（名称・業種・評価・住所・電話・HP・営業時間）が揃わないことが多い

## ツールの流れ

1. 左側に店の一覧が並んだ状態にする（ユーザーが検索）
2. ツールが一覧を自動スクロールしてカードを増やす（最大 120 件）
3. 各店舗の `/maps/place/` URL を覚える
4. 1 件ずつ詳細パネル相当の URL を開き、住所・電話などを拾う
5. 次の店へ（Governor の休憩あり）

`go_next_page` は HTML の「次へ」ではなく、左の `div[role="feed"]` をスクロールしてカードを増やす処理です。

## ページ構造メモ

| 種別 | URL パターン |
|------|----------------|
| 一覧 | `https://www.google.com/maps/search/...` など。左に `div[role="feed"]` |
| 詳細 | `https://www.google.com/maps/place/...`（マップ内パネル） |

### 一覧

- 店舗リンク: `div[role="feed"] a[href*="/maps/place/"]`
- 1 検索あたり最大 **120** 件
- 末尾メッセージ例: 「リストの最後に到達しました」

### 詳細パネル

| CSV 列 | 取得元 |
|--------|--------|
| 企業名 | `h1` |
| 郵便番号 | 住所先頭の `〒` があれば分割 |
| 住所 | `button[data-item-id="address"]` の aria-label |
| 電話番号 | `button[data-item-id^="phone"]` |
| メールアドレス | パネルに無いことが多いため空欄 |
| 担当者名 | パネルに無いことが多いため空欄 |
| 掲載サイト | Google マップ |
| 業種 | 評価付近のカテゴリボタン |
| 評価 | 星の aria-label |
| HP | `a[data-item-id="authority"]` |
| 営業時間 | `button[data-item-id="oh"]` など |

**電話番号が取れない店舗、090・080・070 の携帯電話は CSV に保存しません。**

## 使い方

1. 収集サイト: **Google マップ** を選択
2. [開く] → 黄色い帯の Chrome でエリア・キーワードを検索
3. **左側に店のカードが並んだ状態** で [収集開始]
4. 詳細パネルだけが開いている状態では収集できません
5. ペースは **安全** を推奨します（bot 判定を避けるため）

募集地フィルタをオンにすると、**住所に選んだ県・市のどれか** が含まれる店舗だけを保存します（複数登録可）。

## 注意

- 1 検索あたり約 120 件が上限です。それ以上は検索条件を変えて、別の収集として実行してください
- 1 日の取得量も控えめにしてください
- 確認画面（同意・「ロボットではありません」など）が出たら、収集を止めて人手で戻してください
- Governor の休憩設定を守り、短時間での大量アクセスを避けてください
