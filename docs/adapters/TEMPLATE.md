## テスト手順

1. `[開く]` でトップページを開く
2. 手動で検索し一覧ページまで進む
3. `[収集開始]` で URL キャッシュ → 詳細取得
4. CSV・ログを確認

## 備考

CSV への保存時、090 / 080 / 070 の携帯電話と実装済みリストの既出は、サイトを問わず自動で除外されます。
アダプタ側で特別な処理を書かなくて構いません。
