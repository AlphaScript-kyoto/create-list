## ページ構造メモ

| 種別 | URL パターン |
|------|----------------|
| 一覧 | `https://beauty.hotpepper.jp/pre26/` など。次ページは `/PN2/` `/PN3/` |
| 詳細 | `https://beauty.hotpepper.jp/slnH000061467/` |
| 電話 | `https://beauty.hotpepper.jp/slnH000061467/tel/`（詳細の「番号を表示」リンク） |

### 一覧ページ

- サロン名リンク: `h3.slnName a`
- 次ページ: `a.iS.arrowPagingR`（「次へ」「次の20件」）

### 詳細ページ

| CSV 列 | 取得元 |
|--------|--------|
| 企業名 | JSON-LD の `HairSalon` / `BeautySalon` の `name`（なければ h1） |
| 住所 | JSON-LD の `address`（なければサロンデータ表の「住所」） |
| 電話番号 | JSON-LD の `telephone`。無いときだけ「番号を表示」先の `/tel/` を開く |
| 掲載サイト | ホットペッパービューティー |
| 詳細URL | サロンページ URL（クエリは除く） |

電話番号が取れないサロンは CSV に保存しません。090 / 080 / 070 と実装済みリストの既出は、他サイトと同じく保存時に除外されます。

## 使い方

1. 収集サイト: **ホットペッパービューティー** を選択
2. [開く] → 黄色い帯の Chrome でエリア・ジャンルを検索
3. サロンのカードが並んだ一覧で [収集開始]
