# 半手動リスト収集ツール

企業・店舗情報を **半自動** で収集し、CSV に保存するデスクトップツールです。  
ブラウザでの検索操作はユーザーが行い、ツールが結果一覧からリンクを辿って情報を取得します。

## 概要

| 項目 | 内容 |
|------|------|
| 対象 OS | Windows 10/11 |
| 言語 | Python 3.11+ |
| GUI | CustomTkinter |
| ブラウザ | Playwright + Google Chrome（隔離プロファイル） |
| 現在の実装範囲 | **Phase 0〜4** |

## 使い方

### 1. 初回セットアップ

```powershell
cd C:\Users\1180075\Desktop\プログラミング\create-list
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
py -3 -m pip install -r requirements.txt
py -3 -m playwright install chromium
```

> Windows では `python` の代わりに `py -3` を使う場合があります。  
> Google Chrome が入っていれば `[開く]` は Chrome で起動します。未インストール時は Chromium にフォールバックします。

### 2. アプリ起動（おすすめ）

フォルダ内の **`半手動リスト収集ツール.vbs`** をダブルクリックしてください。  
黒いコマンド画面は出ません。操作 UI だけが開きます。

デスクトップから開きたいときは、そのファイルを右クリック →「送る」→「デスクトップ（ショートカットを作成）」でも大丈夫です。

ターミナルから起動する場合:

```powershell
py -3 main.py
```

VBS をダブルクリックしても画面が出ないときは、起動エラーのダイアログが出ることがあります。  
ダイアログが出ない場合は、上の `py -3 main.py` で黒い画面にエラー内容が表示されます。

### 3. 収集の流れ

1. 収集サイトで **リクナビNEXT**・**バイトル**・**食べログ**・**エキテン**・**Google マップ** を選択
2. 必要なら **募集地で住所を絞り込む** にチェックし、県・市を **[追加]** で登録（任意・複数可）
   - 例: 京都府 京都市 と 大阪府 大阪市 を両方追加
   - 市を未指定で追加すると、県一致だけで判定します
   - 住所に **どれか1つ** の条件が含まれるものだけを保存します
3. **[開く]** → 黄色い帯の Chrome で地域・キーワードを検索
4. **一覧ページ** で [収集開始]
   - **CSV区切り**: 指定した件数ごとにファイルを分けます（0 なら最後まで 1 ファイル）
   - 画面に **経過時間**（日・時間・分・秒）が表示されます
   - **全サイト共通**: 090・080・070 の携帯電話は CSV に入れません
   - **全サイト共通**: 実装済みリストにある会社は CSV に入れず、無いもの（未実装）だけ保存します
   - リクナビNEXT: URL に `job_search`
     - 電話番号は CSV 化のときにハイフン付き（例: `075-708-7200`）にします
     - 担当者が **その他** から始まる場合は、行は残して担当者名のマスだけ空にします
   - バイトル: URL に `jlist`
   - 食べログ: URL に `rstLst`
     - 電話番号がない店舗は CSV に入れません
     - 住所は **郵便番号**（`601-8017`）と **住所** に分けます
     - ニューオープン一覧の **オープン日** も保存します（例: `オープン日　2026/9/8`）
     - 列名は他サイトと同じ（企業名・郵便番号・住所・電話番号…）です
   - エキテン: お店のカードが並んだ検索結果（URL に `/a` や `/g`）
     - 概要の店舗名・住所・電話（●付きのことも多い）を優先
     - 概要に電話が無ければ「電話する」から取得
     - 電話番号がない店舗は CSV に入れません
   - Google マップ: 左側に店のカードが並んだ検索結果
     - 一覧を自動スクロールしてカードを増やし、1 件ずつ詳細パネルの情報を拾います
     - **1 回の検索でおよそ 120 件まで**（マップ側の一覧上限）
     - 電話・住所はカードではなく詳細パネルから取ります
     - 電話番号がない店舗は CSV に入れません
     - 追加列: **業種**・**評価**・**HP**・**営業時間**
     - 少量の特別収集向けです。ペースは **安全** を推奨します
5. 休憩中は **「休憩中: あと N 秒」** とカウントダウン表示
6. 必要なら **[停止]** で中断
7. **社名（店名）と住所が同じものは CSV に 1 件だけ** 残します

> 詳細ページを開いた状態では収集できません。必ず **一覧ページ** で [収集開始] を押してください。

### 4. 動作確認スクリプト（任意）

```powershell
py -3 scripts\verify_governor.py
```

## 出力ファイル

- CSV: `output/{サイトID}_full_YYYYMMDD_HHMMSS.csv`（UTF-8 BOM）
  - CSV区切りを指定すると `..._part001.csv` `..._part002.csv` のように分かれます
  - 区切り件数に達したファイルは、収集の途中でも開けます

全サイト共通の列は次のとおりです。ページに無い項目は空欄になります。

| 列 | 必須の目安 | 備考 |
|----|------------|------|
| 企業名 | ○ | 店名も含みます |
| 郵便番号 | △ | サイトに無い場合は空欄 |
| 住所 | ○ | 郵便番号は除いた本文 |
| 電話番号 | ○ | ハイフン付き。090・080・070 は全サイトで保存しません |
| メールアドレス | △ | 公開されていないことが多いです |
| 担当者名 | △ | 「その他」から始まる内容は空欄。リクナビNEXT は代表者名で代用することがあります |
| 掲載サイト | ○ | リクナビNEXT / バイトル / 食べログ / エキテン / Google マップ |
| 詳細URL | — | 元ページ |
| 取得日時 | — | 収集時刻 |

食べログだけ、このあとに **オープン日** が入ります（値の例: `オープン日　2026/9/8`）。  
Google マップは、掲載サイトのあとに **業種**・**評価**・**HP**・**営業時間** が入ります。

すでに出した食べログ CSV のオープン日だけ直す場合:

```powershell
py -3 scripts\fix_tabelog_open_date.py
```

元ファイルは `output/tabelog_full_....csv.bak` に残します。

すでに出した CSV から携帯電話行だけ除く場合:

```powershell
py -3 scripts\filter_mobile_phones.py
```

すでに出した CSV の電話にハイフンを付け、担当者の「その他」を空欄にする場合:

```powershell
py -3 scripts\fix_csv_phone_contact.py
```

特定のファイルだけ直す例:

```powershell
py -3 scripts\fix_csv_phone_contact.py output\rikunabi_next_full_20260820_100029.csv
```

- URL キャッシュ: `output/{サイトID}_urls_YYYYMMDD_HHMMSS.txt`
- ブラウザプロファイル: `output/.browser_profile/chrome/`（本体 Chrome と隔離）
- ログ: `logs/app.log`

## 募集地フィルタ（任意）

仕事の募集地と本社が離れているケースや、複数エリアをまとめて集めたいときに使えます。

1. 操作画面で **募集地で住所を絞り込む（任意）** にチェック
2. **県** と **市** を選び、**[追加]** を押す（何件でも追加できます）
   - 市は未指定でも追加できます（県一致）
3. リストにない町村は、市の欄へ手入力してから [追加]
4. 不要な行は **[削除]**、まとめて消すなら **[すべて解除]**
5. いつもどおり [収集開始]

オンのときは、本社所在地・所在地・住所に **登録した県・市のどれか** が含まれるものだけ CSV に保存します。  
オフのときは、この絞り込みは行いません。

## 実装済みリスト（重複回避）

`output/現状のmplist/実装済みリスト.csv` は、いままで積み重なった会社の一覧です。  
**オフにはできません。** 既存サイトも、これから足すサイトも、CSV に書く直前で同じルールです。

```text
収集する
  → 090 / 080 / 070 なら CSV に出さない
  → 実装済みリストと照合する（同じ電話番号なら既出）
  → 既出はスキップ
  → 未実装だけ output に CSV を置く
  → その新規分を実装済みリストの末尾にも足す
```

チェックを付ける必要はありません。リストファイルがあれば、起動時からこの動きです。

### すでに出した CSV から既出を除く

このスクリプトは、過去の CSV をあとから見分ける用です。実装済みリストへは自動では足しません。

```powershell
py -3 scripts\filter_known_list.py output\rikunabi_next_full_20260820_100029.csv
```

元ファイルはそのまま残し、`*_未登録.csv` に「まだリストに無い会社」だけ書き出します。

索引を先に作っておきたいとき:

```powershell
py -3 scripts\build_known_index.py
```

## 設定（config.json）

| キー | 説明 |
|------|------|
| `csv_flush_every` | 何件書くたびにディスクへ書き出すか |
| `csv_rows_per_file` | CSV を何件ごとに分けるか。0 なら 1 ファイル |
| `company_filter` | 大手・従業員数の除外（中小・零細向け） |
| `pace_multipliers` | 安全 / 標準 / 速め。**休憩秒数にだけ**倍率をかける |
| `browser.incognito` | true なら起動のたびにプロファイルをリセット |
| `browser.channel` | `"chrome"` = インストール済み Chrome を使用 |
| `browser.clear_storage_on_open` | 起動時に Cookie をクリア |
| `known_list` | 実装済みリストのパス。ファイルがあれば必ず照合（未登録だけ CSV） |

## 中小・零細向けフィルタ

バイトルなどで大手企業を CSV に入れないための設定です（`config.json` の `company_filter`）。

| 項目 | 初期値 | 説明 |
|------|--------|------|
| `enabled` | true | false でフィルタ無効 |
| `max_employees` | 50 | 事業主情報の従業員数がこの人数を超えたら除外。0 で人数判定オフ |
| `exclude_name_keywords` | アマゾン など | 社名に含まれると除外（自分で追加・削除できます） |

アマゾンジャパン合同会社は社名キーワードで除外されます。電話番号ボタンは、除外が決まった時点では押しません。

## 負荷制御（Governor）

収集中は、詳細ページを **1〜5 件（毎回ランダム）** 処理するたびに休憩します。固定間隔にはしません。

| 項目 | 値 |
|------|------|
| 何件ごとに休むか | `batch_min=1` 〜 `batch_max=5`（毎回ランダム） |
| 休憩秒数（標準） | `rest_min_sec=30` 〜 `rest_max_sec=300`（毎回ランダム） |
| ページ遷移の待ち | `page_delay_min_sec=1.0` 〜 `page_delay_max_sec=3.0`（毎回ランダム） |

ペースは **休憩秒数にだけ** 倍率がかかります（件数の幅は常に 1〜5 件）。

| ペース | 倍率 | 休憩の目安 |
|--------|------|------------|
| 安全 | ×1.5 | 約 45〜450 秒 |
| 標準 | ×1.0 | 30〜300 秒 |
| 速め | ×0.7 | 約 21〜210 秒 |

ログ例:

```
[休憩] 87秒お休みします
[再開] 収集を再開します
```

画面には休憩中の残り秒数カウントダウンも表示されます。

## サイトの手動追加（sites.json）

**コードを書かずに** サイト名とトップ URL を追加できます。  
プロジェクト直下の `sites.json` を編集し、アプリを再起動してください。

### 最小例（[開く] のみ）

```json
{
  "sites": [
    {
      "site_id": "my_site",
      "display_name": "自社ポータル",
      "top_url": "https://www.example.co.jp/",
      "enabled": true,
      "notes": "規約確認済み 2026-08-18"
    }
  ]
}
```

| キー | 必須 | 説明 |
|------|------|------|
| `site_id` | ○ | 英数字・underscore の ID（CSV ファイル名に使用） |
| `display_name` | ○ | ドロップダウンに表示する名前 |
| `top_url` | ○ | [開く] で開く URL |
| `enabled` | — | `false` なら一覧に出さない（既定: true） |
| `notes` | — | メモ（アプリでは未使用） |

### 収集も有効にする場合（selectors を追加）

```json
{
  "site_id": "my_site",
  "display_name": "自社ポータル",
  "top_url": "https://www.example.co.jp/",
  "enabled": true,
  "selectors": {
    "list_url_contains": "/results",
    "list_link": "a.detail-link",
    "next_page": "a.next-page",
    "company_name": "h1.name",
    "address": ".address",
    "phone": ".phone"
  }
}
```

| セレクタ | 必須 | 説明 |
|----------|------|------|
| `list_link` | ○ | 一覧の詳細リンク |
| `company_name` | ○ | 詳細ページの会社名 |
| `address` | ○ | 住所 |
| `phone` | ○ | 電話番号 |
| `list_url_contains` | — | 一覧 URL の判定用文字列 |
| `next_page` | — | 次ページリンク（なければ 1 ページのみ） |

詳細は `sites.example.json` を参照してください。

## 新サイトの追加（Python アダプタ）

複雑なサイトは引き続き Python で実装できます。

1. `docs/adapters/TEMPLATE.md` をコピーして規約確認を記録
2. `adapters/_template.py` を参考に `adapters/site_xxx.py` を作成
3. `adapters/registry.py` の `_BUILTIN_ADAPTERS` に登録

## 注意事項

操作画面の下部にも、次の内容を表示しています。

- 短時間に大量のアクセスを行うと、アクセス先のサイト側でアクセス制限やブロックされる恐れがあります。
- 本機能のアクセスには、ご利用者様ご自身の IP アドレスが使用されます。過度なアクセスを行った場合、該当サイトへ通常通りアクセスできなくなる可能性があります。
- 本機能のご利用により発生したアクセス制限、ブロック、その他のトラブルにつきましては、ツール制作者側では責任を負いかねます。
- ご利用の際は、ご利用者様ご自身の責任において、アクセス先サイトに過度な負荷をかけないよう、節度を持ってご利用ください。

そのほか:

- 本番サイトを追加する前に、利用規約・robots.txt を確認してください
- Google マップは少量の特別収集向けです。1 検索あたり約 120 件、ペースは安全を推奨します
- 詳細仕様は `SPEC.md` を参照してください
